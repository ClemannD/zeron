# Usage cards

A Zeron plugin. `init.luau` is its code, `zeron-plugin.json` its manifest (permissions, what it may change, its tools) and `zeron.luau` Zeron's helpers. Zeron re-signs and reloads it each time you save.

How to write one: /Users/dclemann/.zeron/docs/plugins.md

Check your work with the `plugin_status` tool (`snapshot: true` for a picture of where it shows), and `describe_elements` for where it can go.
