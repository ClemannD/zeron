# Open local files in Finder

- [ ] Add an **Open in Finder** action wherever the app shows local files, such
  as file trees, search results, tabs, and file references.
- [ ] Open the file's containing folder in Finder and select the file when
  possible; for folders, open the folder itself.
- [ ] Keep the action available only for files on the local machine, and define
  clear behavior for remote workspace files.
